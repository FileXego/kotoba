# Kotoba 现代东方书刊 UI 设计

## 目标

把 Kotoba 从通用卡片式留言板升级为可长期扩展的个人统一工程界面：以现代东方书刊为视觉骨架，兼顾中文与日文阅读，在桌面和移动端覆盖首页、对话、收藏、个人资料、管理与认证界面。

## 设计方向

- **骨架：活字与版记。** 使用偏轴书页网格、页码、章节编号、日期和竖向版记组织信息。
- **动态：展卷。** 页面和内容进入时沿横向轻微展开，时长短、位移小，不模拟真实翻页。
- **背景：淡墨。** 墨色只作为低对比氛围，不覆盖正文，也不承担交互状态。
- **细节：朱印与书脊。** 当前页面、发布动作、选中态和回复层级使用朱砂色及细线表达。
- **字体：理性宋体 + 私人批注。** 思源宋体承载标题和正文；霞鹜文楷仅用于题签、空状态与签名。

## 版式

桌面采用三列编辑网格：左侧窄版记、主内容页、右侧留白。主体不再严格居中，形成书页偏轴感。版记只显示章节、当前页面、日期和实时状态，不放关键操作。小于 860px 时版记折叠为内容顶部的横向页眉；小于 640px 时保持现有底部导航，但重绘为书签式导航。

消息不再表现为悬浮白卡，而是同一张纸上的独立条目：细书脊、编号、作者、正文和版尾操作形成稳定阅读节奏。回复使用连续竖线与缩进表示层级，避免套娃卡片。

## 四种书刊版本

所有主题共享结构、间距和动效，仅替换设计令牌与材质：

- `light`：**宣纸**，暖白纸、松墨字、朱砂印。
- `dark`：**夜卷**，靛黑纸、月白字、赭红印。
- `sumi`：**松烟**，青黑纸、灰白字、银灰线。
- `sakura`：**樱笺**，淡樱纸、紫墨字、胭脂印。

每套主题由背景、纸面、文字、次要文字、印色、书脊线、纹理透明度和阴影等统一令牌驱动。

## 材质与字体资产

新增项目专属的 SVG 材质资产：宣纸纤维、淡墨云痕与松烟颗粒。资产低对比、可平铺、无文字内容，CSS 关闭背景图片时不影响层级与可读性。字体采用开放许可、自托管资源；首版优先通过 `@fontsource` 管理字体文件与缓存，由构建系统输出版本化资源。

## 动效系统

只引入一个动效入口。Motion 提供路由切换、列表错落入场和状态印记反馈；所有时长、缓动和位移集中在 `client/src/design/motion.ts`。页面进入采用透明度 + 轻微横向缩放，消息列表延迟不超过 240ms。`prefers-reduced-motion` 下取消位移、缩放和背景呼吸，仅保留即时透明度反馈。

## 组件结构

- `EditorialFrame`：桌面版记、偏轴书页、移动页眉和路由转场容器。
- `FolioRail`：章节号、路由名称、日期与实时状态。
- `PageTransition`：统一页面展卷动画。
- 现有 `Header`、`MessageCard`、`SubmitForm`、`MePage`、`AdminPanel` 保留业务职责，只增加语义标记和视觉挂钩。

## 无障碍与性能

- 所有关键操作保持文字或现有可访问名称，装饰元素均 `aria-hidden`。
- 保持焦点轮廓、44px 移动触控目标和足够对比度。
- 字体与纹理本地缓存；材质不参与首屏内容布局。
- 动效不阻塞输入、网络请求或路由状态。
- 验收宽度：375、390、430、768、1024、1440px。

## 验收标准

1. 五个现有路由和认证状态使用同一编辑设计语言。
2. 四套主题均可读、可切换，布局不跳动。
3. 桌面有偏轴版记，移动端无横向溢出且底部导航不遮挡内容。
4. 减少动态偏好下不出现卷页位移、墨迹呼吸或错落动画。
5. `bun run --cwd client build` 与 `bun run --cwd client lint` 通过。
